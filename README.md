# Executive Hotel Booking EDA

## Day 15 Data Science Assignment

This project presents an end-to-end Exploratory Data Analysis (EDA) of a hotel booking dataset.

## Project Objective

The objective is to understand hotel booking behavior, assess data quality, clean and preprocess the data, identify important patterns, and generate actionable business insights for hotel management.

## Analysis Performed

- Dataset understanding and overview
- Missing value analysis
- Duplicate record analysis
- Data type validation
- Inconsistent value detection and standardization
- Outlier analysis
- Data cleaning and preprocessing
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Group-wise analysis
- Correlation analysis
- Data visualization using Matplotlib and Seaborn
- Business insights
- Management recommendations

## Key Findings

- Final analytical dataset contains 25,000 unique bookings.
- Overall cancellation rate is approximately 72.18%.
- Average ADR is approximately 140.59.
- Average stay length is approximately 3.69 nights.
- Average satisfaction score is approximately 3.85.
- Longer booking lead times are associated with substantially higher cancellation rates.
- Online TA is a major booking segment with relatively high cancellation.
- Resort Hotel has a higher average ADR, while City Hotel has greater booking volume.
- Approximately 11.95% of bookings show a difference between reserved and assigned room type.

## Conclusion

The analysis identifies high cancellation rates as a major business concern. Longer booking lead times, OTA bookings, hotel-type differences, and room assignment changes provide important areas for management attention. The findings support improved cancellation management, channel management, pricing strategies, operational monitoring, and regular KPI tracking.
